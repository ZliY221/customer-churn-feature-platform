# 留存运营工作台

`/console` 提供客户组合、风险分层、高风险客户优先队列和运营任务看板。页面不依赖外部资源，可随查询服务一起部署。

## 风险分层

平台按流失概率划分四档风险：

- `CRITICAL`：概率不低于 0.80，建议优先人工联系；
- `HIGH`：概率不低于 0.60，建议配置定向权益；
- `WATCH`：概率不低于 0.40，建议进行活跃跟进；
- `STABLE`：低于 0.40，进入常规维护。

风险分层用于运营排序，不替代模型决策阈值。预测结果、模型阈值和风险分层同时保留，避免混淆模型结论与运营策略。

## 任务闭环

运营人员可以从优先队列创建任务，并在 `OPEN`、`IN_PROGRESS`、`COMPLETED`、`DISMISSED` 四个状态之间流转。任务记录保存预测编号、匿名客户键、风险等级、策略、负责人和模型指纹。

同一预测只能创建一个任务，防止重复触达。模型批次变化不会覆盖已有任务的模型指纹，历史任务仍能追溯到创建时使用的模型版本。
