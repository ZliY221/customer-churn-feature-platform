# 需求与验收标准

## 业务目标

系统基于匿名客户行为事件构建时间一致的离线特征，预测客户在标签窗口内是否停止活跃，并提供训练、批量推理、在线查询与漂移监控能力。

## 关键约束

- 客户标识全部为确定性合成键，不包含姓名、电话、邮箱、地址或真实账号映射。
- 特征只允许使用观测截止时间及之前的数据，标签只使用未来窗口，防止标签泄漏。
- 训练、验证和测试按时间切分，不使用随机切分代替线上时间演进。
- 分类阈值在验证集上确定，测试集只用于最终评估。
- 模型指标至少包含 ROC-AUC、PR-AUC、召回率、精确率和混淆矩阵。
- 训练产物必须记录数据指纹、参数、特征清单、指标和模型文件哈希。
- 批量推理必须幂等，在线接口不直接读取训练进程内存。
- 数据漂移和预测漂移使用固定基线与机器可读报告。

## 首个版本验收

- 生成结果在相同参数下逐字节可复现。
- 事件 ID 全局唯一，匿名客户键格式稳定。
- 所有事件通过显式契约校验。
- 订单金额只在成交事件出现，并使用两位小数字符串。
- 事件时间不晚于摄取时间，摄取延迟不超过五分钟。
- 自动化测试覆盖确定性、唯一性、隐私字段、时间和金额边界。
